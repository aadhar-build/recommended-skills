# deprecated

Skills that are **no longer recommended** but are kept for reference and history.

## When a skill moves here
- It has been superseded by another skill in this repo (name the replacement in the skill's own `SKILL.md`).
- The tool, CLI, or service it drives is gone or permanently unavailable.
- It has been proven to produce bad agent behaviour and should not be installed.

## Rules
- **Never delete a skill — move it here.** The git history and the file both stay.
- Add a one-line `> Deprecated YYYY-MM-DD — superseded by <x> / reason` note at the top of the skill's `SKILL.md` when moving it.
- Nothing here should be installed into a live agent.
