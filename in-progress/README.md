# in-progress

Skills that are **being written or trialled** and are not yet recommended for general use.

## When a skill moves here
- It is a new draft that has not been exercised on real work yet.
- It depends on tooling that is not yet installed or shipped.
- It is being reworked and is temporarily unreliable.

## When a skill moves out
Promote it into a topic folder once it has been run end-to-end at least once on a
real task and its `SKILL.md` describes what it actually does.

## Rules
- Install these at your own risk; treat their behaviour as unverified.
- A skill that stalls here indefinitely belongs in `deprecated/`, not in limbo.
