# misc — miscellaneous

Skills that are live and recommended, but don't yet belong to any of the topic
categories (`engineering/`, `knowledge/`, `integrations/`, `productivity/`).

This is a **landing zone, not a dumping ground**. A skill sits here only while its
category is genuinely unclear. If three or more skills accumulate around a common
theme, promote them into a new topic folder instead of leaving them here.

It is currently empty — every skill in this repo has a real category.
